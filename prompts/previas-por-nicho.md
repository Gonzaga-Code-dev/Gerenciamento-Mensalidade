# Prompts de prévia por nicho · Gonzaga Code

Um prompt por nicho da aba "Nichos" da planilha de prospecção. Para usar:

1. Copie o prompt do nicho.
2. Troque tudo que está entre colchetes pelos dados do negócio (do Google Maps e do WhatsApp Business).
3. O que você não souber, apague a linha. **Nunca invente**: o prompt já instrui a não preencher o que falta.
4. Mande aqui no estúdio, junto com os prints do Maps e do catálogo do WhatsApp, se tiver.

Campos comuns a todos:

```
NOME: [nome do negócio como aparece no Google]
BAIRRO: [bairro]
ENDEREÇO: [rua, número, sala, bairro, CEP]
WHATSAPP: [número com DDD]
NOTA NO GOOGLE: [ex.: 5,0 com 120 avaliações]
HORÁRIOS: [dias e horários]
SERVIÇOS: [lista exata do catálogo, do Maps ou do Instagram]
INSTAGRAM: [@]
```

## Regras que valem para todos

- **Prévia:** faixa no topo "Prévia desenvolvida por Gonzaga Code para [NOME]" e `noindex`.
- **Identidade:** cada site com paleta, fontes e ritmo próprios. Nunca repetir o visual de outro site do estúdio.
- **Celular primeiro:** botão flutuante de WhatsApp no celular e nenhuma rolagem lateral.
- **Fotos:** sem fotos reais do cliente na prévia, a menos que ele mesmo publique. Espaços indicados com "Espaço para foto de...".
- **Nada inventado:** nenhum serviço, número, depoimento, certificação ou horário que não tenha vindo dos dados.
- **SEO pronto para a versão oficial:** título "[Nome] | [Nicho] em [Bairro] – SP", descrição com nicho e bairro, dados estruturados do tipo certo e Open Graph.
